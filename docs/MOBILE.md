# CLover 스마트폰 앱 개발

## 구성

- `mobile/`: Expo + React Native + TypeScript Android/iOS 앱.
- `backend/`: 기존 FastAPI 인증·돌봄 API와 기관 서버의 Ollama/Qwen2.5 0.5B.
- `frontend/`: 이전 웹 요청 폼 참고 파일. 신규 제품 화면은 mobile에서 개발합니다.

모델은 휴대폰에 설치하지 않습니다. 앱의 로그인과 돌봄 원문은 기관의 API로 전송되고, 추론은 그 기관 PC에서만 실행됩니다. 휴대폰 오프라인 단독 추론과는 다릅니다. 인터넷 LLM API나 앱 분석 SDK를 추가하지 않았습니다.

## 구현 화면

- 서버 연결 상태, 회원가입(어르신/사회복지사/요양보호사)·로그인·로그아웃.
- 어르신: 오늘의 안부, 도움 요청, 내 요청 목록·내용·검토 상태, 반복 요청 안내.
- 사회복지사: 미배정 접수함, 담당 수락, 내 담당 목록·원문 확인, 위험도 수동 확정.
- 관리자: 승인 대기 계정 목록과 승인.
- 관리자/사회복지사: 내부 모델을 사용하는 일반 안내문 초안.
- 요양보호사 계정은 로그인까지 지원하며 일정·수락·거절은 기존 API 미구현 상태를 화면에 표시합니다.

## 개발 시작

1. 루트 README의 로컬 모델/백엔드 설치를 완료합니다.
2. Node.js 22.13 이상 (권장: 24 LTS)와 휴대폰의 Expo Go를 준비합니다. 설치한 Expo Go와 package.json의 Expo SDK 호환성을 확인하세요.
3. mobile 폴더에서 다음을 실행합니다.

```sh
npm ci
```

4. `mobile/.env.example`을 `mobile/.env`로 복사하고 기관 개발 서버 주소를 입력합니다.

```dotenv
EXPO_PUBLIC_API_URL=https://기관_API_주소
```

`EXPO_PUBLIC_*`는 앱에 포함되는 공개 설정입니다. 인증키나 비밀번호를 넣지 않습니다. JWT는 앱 메모리에만 보관하고 재시작 시 다시 로그인합니다. 입력 원문과 요청 목록은 파일로 저장하지 않습니다.

5. 같은 기관 개발망에서 실행합니다.

```sh
npm start
```

QR 코드를 Expo Go로 엽니다. 외부 tunnel은 사용하지 마세요. 실기기에서는 `localhost`가 PC가 아니라 휴대폰을 가리킵니다.

## 개발망 HTTP 예외 (가상 데이터만)

신뢰할 수 있는 테스트 Wi-Fi의 사설 IP를 사용할 때만 다음 설정을 추가할 수 있습니다.

```dotenv
EXPO_PUBLIC_API_URL=http://192.168.0.10:8000
EXPO_PUBLIC_ALLOW_INSECURE_DEV=true
```

백엔드를 테스트 PC에서 `python -m uvicorn main:app --host 0.0.0.0 --port 8000 --no-access-log --workers 1`로 실행하고 Windows 방화벽에서 기관 개발망에만 8000 접근을 허용합니다. 모델의 11434 포트는 loopback으로 유지합니다. 라우터 포트포워딩은 하지 마세요.

HTTP는 개발 모드에서 명시적으로 허용한 사설 IPv4/localhost만 받습니다. OS나 Expo Go의 HTTP 정책에 따라 연결이 차단될 수 있으며, 그 경우 신뢰된 HTTPS 개발 주소를 사용하세요. 실제 이용자 데이터에는 HTTPS가 필수입니다. 운영 빌드는 HTTP 설정을 거부합니다.

## 실제 운영

- 기관 승인 도메인·TLS 인증서·VPN/접근 제한·API 앞단 속도 제한을 구성합니다.
- 앱 클라이언트만으로 임의 서버 연결을 안전하게 만들 수 없으므로 배포 설정의 API 주소를 기관이 검증해야 합니다.
- 스마트폰 앱은 직접 Ollama에 접속하지 않습니다. DB/암호화 키/모델은 기관 서버에 둡니다.
- 백그라운드에서 화면을 가리는 것은 UI 보호이며 OS 스크린샷·루팅 장비·메모리 공격을 차단하는 완전한 보안 기능이 아닙니다.
- 네트워크 중단 시 돌봄 요청을 자동 재전송하지 않습니다. 서버에 저장되었으나 응답을 못 받은 경우가 있어 목록 확인 후 재시도하세요.
- AI/통신 장애는 119 자동 신고를 대신하지 않습니다. 긴급 상황 안내를 앱에 표시합니다.

## 검증과 배포

```sh
npm run typecheck
npm test
npx expo export --platform android --platform ios
```

Metro 번들 생성은 APK/IPA 설치 테스트가 아닙니다. 실제 Android/iPhone에서 로그인·승인·접수·검토·로그아웃·네트워크 오류·접근성 확인 후 배포하세요. Android 서명 빌드와 iOS 서명/스토어 등록은 이번 단계에서 수행하지 않습니다.
