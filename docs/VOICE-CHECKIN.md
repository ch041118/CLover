# 접수 완료 음성과 자동 음성 확인

## 요청 접수 완료 안내

글로 보내거나 음성으로 확인한 도움 요청이 서버에 정상 저장된 경우, 휴대폰 음성으로 “요청이 정상적으로 접수되었습니다. 담당자가 확인할 예정입니다.”라고 알립니다. 이는 담당자의 검토가 끝났다는 뜻이 아닙니다. 긴급 안내가 반환되면 이어 읽습니다. 상담 원문이나 개인정보는 읽어 주지 않습니다.

네트워크 오류·실패·취소에는 성공 안내를 재생하지 않습니다. 저장은 성공했지만 음성 재생이 실패하면 접수 완료와 음성 안내 실패를 화면에서 구분합니다. 음성 실패를 이유로 요청을 다시 접수하지 않습니다. 화면 이동·로그아웃·백그라운드 전환 시 음성을 중단합니다.

## 클릭 대신 음성으로 하루 확인

어르신 홈 화면의 **말로 하는 하루 확인**에서 최초 한 번 안내에 동의하고 켭니다. 마이크 권한을 허용해야 하며, 이후 매일 별도의 출석 버튼을 누를 필요 없이 홈 화면에서 질문합니다.

- 한국 시간 오전 9시부터 오후 8시 전까지 질문합니다.
- “안녕하세요. 오늘 어떠세요?”라는 안내를 마친 뒤 8초간 답변을 녹음합니다. 질문 재생 중에는 녹음하지 않습니다.
- “네”, “잘 지내요”, “괜찮아요”처럼 지원하는 답변이 인식되면 하루 응답을 기록하고 그날은 다시 묻지 않습니다.
- “도와주세요”, “아파요”, “괜찮지 않아요” 등은 도움 필요 응답으로 구분합니다. 응답했다는 기록만 남기며 건강 상태가 양호하다고 판단하지 않습니다. 도움 요청 화면 이용과 긴급 연락 안내를 들려줍니다.
- 무음 또는 답변을 확실하게 인식하지 못하면 5분 뒤 다시 묻습니다. 하루 최대 3회 질문하며 이후는 미확인 상태로 남깁니다.
- 음성 모델·네트워크·기기 오류는 응답 확인과 구분합니다. 오류나 중단도 시도 횟수에 포함해 무한히 질문하지 않습니다.
- 도중에 **지금 질문·녹음 멈추기**, 대기 중에 **자동 음성 확인 끄기**로 중단할 수 있습니다.

시도 횟수·다음 확인 시각·당일 응답 상태는 서버에 저장합니다. 홈을 다시 열거나 다른 기기에서 로그인해도 이미 확인한 날에 중복 질문하지 않으며, 동시 시작 요청도 한 건만 허용합니다. 기존 출석 데이터와 일일 중복 방지 조건을 공유합니다. 설정을 껐다 켠다고 하루 횟수가 초기화되지 않습니다.

## 실제 동작 범위

현재는 **어르신 홈 화면이 전면에 있고 휴대폰 화면이 켜져 있는 동안** 동작합니다. 앱 종료·화면 잠금·다른 메뉴에서는 질문·녹음을 멈춥니다. 재질문 시각이 지나면 홈으로 돌아온 뒤 다음 확인 주기에서 다시 묻습니다. 15초 간격으로 서버 상태를 확인하므로 정확히 5분 정각에 재생된다는 보장은 없습니다.

휴대폰을 잠근 채 상시 대화하는 백그라운드 서비스, 예약 전화, 자동 119 신고, 가족·사회복지사에게 푸시 알림을 보내는 기능은 포함하지 않습니다. 도움 필요 응답 자체가 새 돌봄 요청을 자동 접수하는 것도 아닙니다. 이 기능은 응답 확인이며 미응답만으로 위험이나 부재를 확정하지 않습니다.

기기 TTS로 안내하므로 한국어 음성·미디어 음량·무음 설정을 확인하세요. 이어폰이나 블루투스가 연결돼 있으면 해당 출력 장치로 들릴 수 있습니다. 앱은 전화 수화기 출력을 기본으로 요청하지 않지만 기기의 출력 장치나 음량을 강제로 바꾸지 않습니다. iPhone 무음 모드와 실제 기기별 음성 출력은 별도 확인이 필요합니다.

음성은 기관 PC의 기존 모델로 변환합니다. 녹음 파일은 처리 후 정리하고, 출석에는 원음이나 답변 원문을 저장하지 않습니다. 미지원 표현·소음·사투리·인식 오류는 미확인으로 남을 수 있으므로 실사용자 음성으로 검증해야 합니다.

## 설치와 업데이트

기존 DB와 암호화 키를 백업한 뒤 backend 가상환경에서 실행합니다.

```bat
python manage.py init-db
```

`checkin_preferences`, `checkin_days` 테이블을 추가합니다. 기존 음성 인식 모델 설치와 `SPEECH_ENABLED=true` 설정이 필요합니다. 서버를 재시작합니다.

mobile에서 실행합니다.

```bat
npm ci
npm start -- --clear
```

`expo-speech`가 추가됐습니다. 직접 만든 개발 빌드·배포 앱은 네이티브 모듈과 마이크 안내 문구 반영을 위해 다시 빌드해야 합니다. SDK 57 호환 Expo Go는 해당 모듈 지원 여부를 확인하세요.

## 검증

서버 테스트는 하루 중복 방지, 5분 대기·3회 제한, 다음 날 재개, 야간 차단, 동의 철회, 다른 사용자 접근 차단, 동시 시작, 기술 오류 및 도움 필요 응답 구분을 확인합니다. 실제 스피커 재생·마이크 녹음·음성 인식 품질·잠금 전환은 실기기 확인이 필요합니다.
